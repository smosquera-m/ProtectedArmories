## 📌 Automatic Git Push Workflow
- **MANDATORY:** After completing and verifying any code change or feature (`python dev.py all`), **ALWAYS stage (`git add .`), commit, and push (`git push origin main`)** automatically.
- Do not wait or ask for confirmation to push clean, passing code to Git.
