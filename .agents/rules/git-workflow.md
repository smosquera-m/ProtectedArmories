# Automatic Git Workflow Rule

> [!IMPORTANT]
> **MANDATORY RULE FOR ALL TASKS:**
> Whenever you complete a feature, bug fix, refactoring, or code modification:
> 1. Run automated tests and static analysis (`python dev.py all`).
> 2. Once verified clean and passing, **ALWAYS automatically stage, commit, and push the changes to Git (`git push origin main`)** before concluding the task or turn.
> 3. Never ask if you should upload to Git—do it automatically as part of the task completion workflow.
